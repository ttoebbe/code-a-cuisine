### A1.5 im Detail — die Rechnung

Der Fehler ist eine Einheiten-Verwechslung: **die Tellergröße hängt an der
Viewport-Höhe, die Containerbreite an der Viewport-Breite.**

| Größe                    | Formel                                | Quelle                                                      |
| ------------------------ | ------------------------------------- | ----------------------------------------------------------- |
| `--plate-span`           | `100vh - var(--footer-height)`        | [home.scss:139](../../src/app/home/home.scss#L139)          |
| `--plate-size`           | `--plate-span / 2.11`                 | [home.scss:140](../../src/app/home/home.scss#L140)          |
| Container-Breite (≥768)  | `50%` der Hero-Padding-Box            | [home.scss:153](../../src/app/home/home.scss#L153)          |
| Container-Breite (≥1440) | `--content-max-width / 2` = **544px** | [home.scss:159](../../src/app/home/home.scss#L159)          |
| Container                | `overflow: hidden`                    | [home.scss:149](../../src/app/home/home.scss#L149)          |
| Teller                   | `position: absolute; right: 0`        | [home.scss:164-165](../../src/app/home/home.scss#L164-L165) |

Weil die Teller **rechtsbündig** in einem Container mit `overflow: hidden` liegen,
landet jeder Überstand **auf der linken Seite** — genau der beschriebene Effekt.
Er tritt ein, sobald `--plate-size` > Containerbreite:

| Viewport    | `--plate-size`             | Container                | Links abgeschnitten |
| ----------- | -------------------------- | ------------------------ | ------------------- |
| 768 × 1024  | (1024−76)/2,11 = **449px** | (768−64)·0,5 = **352px** | **97px**            |
| 1024 × 1024 | 449px                      | (1024−64)·0,5 = 480px    | —                   |
| 1440 × 1024 | 449px                      | 688px                    | —                   |
| 1440 × 1300 | (1300−76)/2,11 = **580px** | **544px** (fix ab 1440)  | **36px**            |
| 1920 × 1440 | (1440−76)/2,11 = **646px** | **544px**                | **102px**           |

Das Clipping tritt also in **zwei** Bereichen auf: im Tablet-Bereich 768–~1050px
und ab 1440px auf hohen Monitoren (Full-HD hochkant, 1440p, große Notebooks).
Auf dem klassischen 1440 × 1024 tritt es nicht auf — deshalb ist es beim Testen
durchgerutscht.
